# 🔢 Simple Calculator by Vaibhav

A responsive and stylish web-based calculator built using **HTML**, **CSS**, and **JavaScript**.  
Designed to perform basic arithmetic operations with a smooth user experience across devices.

---

## 🚀 Features

- Basic operations: ➕ Addition, ➖ Subtraction, ✖ Multiplication, ➗ Division
- Clear (`AC`) and backspace (`DEL`) functionality
- Click-based input with animated buttons
- Mobile-friendly, fully responsive design
- Minimal, modern interface with soft color palette
